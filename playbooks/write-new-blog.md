# Write New Blog Playbook

Enter through `prompts/run-daily-content.md`. Use `templates/content-brief.md` and `templates/article-output.md`; use the blog-specific templates for planning and body structure.

1. Confirm no existing blog, glossary term, or utility owns the same intent.
2. Complete and obtain human approval for the machine-readable brief.
3. Update the SEO article register and build the exact-anchor link plan.
4. Verify source-register IDs and firm/program variation.
5. Draft an answer-first article with the Blog Writer.
6. Complete metadata and insert quality-checked links.
7. Run fact check and the 100-point AI QA rubric.
8. Create the revision hash and run both deterministic validators.
9. Route the exact passing revision to `Human Review`.

Do not approve, publish, or update an external system.
