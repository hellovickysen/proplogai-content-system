# Audit Live Blog and Glossary Library

1. Read system, SEO, linking, facts, content-type, and quality knowledge.
2. Capture the live blog and glossary indexes with a checked date.
3. Discover canonical item URLs and refresh `content-map/live-inventory.csv`.
4. Verify HTTP behaviour, canonical tags, sitemap presence, metadata, headings, and structured data where available.
5. Sample or audit every content item using the matching content-type rules.
6. Map duplicate intents, weak cross-links, orphans, stale claims, source gaps, and missing topics.
7. Write a prioritized report using `templates/site-audit-report.md`.
8. Put fixes in `content-map/refresh-queue.csv`; do not edit production.

Done means every finding has a URL, evidence, priority, and recommended owner or next action.
