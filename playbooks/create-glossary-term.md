# Create a Glossary Term

1. Confirm the term does not already exist under the same or synonymous intent.
2. Check whether a blog, calculator, or product page already defines it.
3. Complete `templates/content-brief.md` with `content_type: "Glossary"`, use `templates/glossary-brief.md` as the planning view, and obtain human brief approval.
4. Verify the definition and any firm-specific variation.
5. Draft with the Glossary Writer, `templates/article-output.md`, and `templates/glossary-output.md`.
6. Add reviewed related terms and one deeper guide only when useful.
7. Update both durable SEO registers and run SEO, fact, and 100-point QA review.
8. Create the revision hash, run both validators, and route the exact revision to human review.
9. Move only a human-approved revision to `content/approved/glossary/`.
