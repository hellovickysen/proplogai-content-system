# Audit Blog Playbook

## Objective

Define the workflow for auditing an existing ProplogAI blog before it is rewritten or republished.

- skills/audit/content-auditor.md

---

## Required Templates

- templates/audit-report.md

---

## Required Checklists

- checklists/blog-quality-checklist.md

---

## Inputs

- Blog URL or Markdown
- Target Keyword
- Search Intent
- Content Type

---

## Workflow

1. Load System Rules.
2. Load required Knowledge files.
3. Load the Content Auditor skill.
4. Read the complete article.
5. Audit using the audit skill.
6. Generate the audit report using the template.
7. Validate against the blog quality checklist.
8. Return the final audit report.

---

## Deliverables

- Completed Audit Report
- Overall Score
- Category Scores
- Rewrite Priority
- Action Plan

---

## Completion Criteria

The playbook is complete only if:

- The audit follows the template.
- Every checklist category is evaluated.
- No rewriting is performed.
- Clear action items are provided.
