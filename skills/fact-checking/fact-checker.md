# Fact Checker

## Responsibility

Verify every claim that could affect money, account rules, eligibility, product expectations, or trust.

Use first-party PropLogAI sources for product claims and the named prop firm's current rule page for firm-specific rules. Record URL, publisher, checked date, supported claim, and limitation. Check calculations independently.

Return `Pass`, `Needs Correction`, or `Blocked`. A missing source is not a pass. Any unresolved product, rule, legal, performance, payout, or eligibility claim blocks approval.
