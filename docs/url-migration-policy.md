# PropLogAI URL Migration Policy

- Standing authorization recorded: 2026-09-24
- Scope: evidence-based URL changes for existing PropLogAI blog and glossary content

Existing URLs may be changed when keyword ownership, search intent, taxonomy, or canonical consolidation provides a documented SEO reason. A URL change is a migration, not a copy edit.

## Required migration package

Every change must record and validate:

1. Existing URL and proposed URL.
2. Primary keyword, intent, and evidence supporting the change.
3. Cannibalisation and backlink/GSC impact assessment.
4. Permanent redirect from the old URL to the exact new canonical URL.
5. Updated canonical, Open Graph URL, sitemap, internal links, breadcrumbs, schema, and navigation references.
6. Preserved publication history and an honest update date.
7. Local build and redirect/canonical regression tests.
8. Post-release HTTP, canonical, sitemap, rendered-link, and GSC verification.

Do not change an established URL merely to make it contain an exact keyword. Preserve it when intent ownership is already correct or when migration risk outweighs the expected gain.

This standing authorization covers local planning and implementation of justified URL migrations. It does not itself deploy changes to production; deployment remains a separate release action.
