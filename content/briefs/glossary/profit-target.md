# Content Brief: Profit Target

## Primary question and promise

Answer **“What is a profit target in a prop firm challenge?”** immediately. Explain the phase-specific net-profit objective, show the arithmetic and make clear that reaching the number does not replace the rest of the current program rules.

## Reader problem

The current page is accurate but compressed. A trader can calculate 8% of a reference amount and still misunderstand the rule by treating the target as a daily quota, ignoring whether positions must be closed, copying one program's percentage to another, or assuming that reaching the number automatically completes the phase.

## Evidence and SEO decision

- Keep `/glossary/profit-target`; it is the established definition owner and no migration is justified.
- Semrush India reports no data for `prop firm profit target`. The broader `profit target` query shows volume 20, CPC $0 and unavailable KD, but it has mixed possible intent.
- GSC returned 0 clicks and 0 impressions for queries containing `profit target` during 6 July–2 October 2026.
- FTMO's current page checked 5 October 2026 lists 10% for its 2-Step Challenge, 5% for Verification and requires the balance to exceed the initial simulated capital with positions closed.
- FundedNext's current Stellar 2-Step page checked 5 October 2026 lists 8% in Phase 1 and 5% in Phase 2, with no profit target on the later FundedNext Account described there.
- Named examples demonstrate variation and must not become a universal range.

## Required teaching path

1. Define the prop-firm profit target in one sentence.
2. Show the arithmetic: `program reference amount × stated target percentage = target amount`.
3. Use a fictional `$100,000 × 8% = $8,000` phase example and label it illustrative.
4. Explain the difference between a target amount and a required ending balance when the program uses the starting amount as its reference.
5. Explain that open-position treatment, closed-position requirements, costs, reset rules and pass conditions depend on the exact program.
6. Use current FTMO and FundedNext examples only to show that phases and percentages differ.
7. Explain why an 8% phase target is not a request to make 8% in one day and is not a reason to increase size.
8. Tell the reader to check the full rule set: loss limits, minimum days, consistency requirements, prohibited practices, KYC and any other named condition.
9. State that funded-stage accounts may have different objectives or no profit target, depending on the agreement.

## Firm/program variation and formula assumptions

- The fictional example uses a stated `$100,000` reference and an 8% target only to demonstrate multiplication.
- Do not imply that 8% is common, standard or suitable.
- Costs and open P&L treatment can affect whether the official dashboard says the target is met.
- The firm's current dashboard, contract and rule page control the account status.
