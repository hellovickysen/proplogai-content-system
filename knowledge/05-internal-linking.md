# Internal Linking

Every link should advance the reader's task.

- Link a technical term to its glossary definition on first useful mention.
- Link a glossary term to one deeper guide where a reader needs application.
- Link cluster articles to the canonical pillar when relevant.
- Link pillars to reviewed supporting pages.
- Link to product pages only when the feature is current and directly relevant.

Verify the destination, canonical URL, title, relevance, and current accuracy before adding it. Do not invent a URL, use arbitrary quotas, repeat exact-match anchors unnaturally, or link to a weak page for SEO. Record missing destinations as content gaps.
