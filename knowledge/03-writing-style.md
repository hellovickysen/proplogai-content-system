# Writing Style

- Lead with the answer, then explain.
- Prefer concrete verbs and familiar words.
- Use active voice and short paragraphs.
- Keep one search intent and one central promise per page.
- Use tables for real comparisons and checklists for observable steps.
- Label hypothetical examples and state every assumption.
- Put a limitation beside the claim it limits.
- Use `PropLogAI` consistently.
- Write `prop firm` as two words unless quoting a brand.

Avoid filler introductions, keyword stuffing, dramatic claims, fake quotations, generic motivation, and repetitive conclusions. A CTA is optional. When used, it should invite a useful next step without pressure.
