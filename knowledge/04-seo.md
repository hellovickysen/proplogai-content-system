# SEO Rules

## Ownership

The SEO Editor owns search intent, query-to-URL mapping, cannibalisation review, pillar and cluster assignment, metadata, and internal-link placement.

## Process

1. Refresh the live blog and glossary inventory.
2. Decide whether to create, update, consolidate, redirect, or defer.
3. Assign one primary query and one intent to one canonical URL.
4. Record supporting queries only when they share the same intent.
5. Check overlap across both blogs and glossary terms.
6. Add accurate title, description, slug, H1, headings, and useful internal links.
7. Record whether evidence came from Search Console, current search results, or editorial judgment.

## Search-data sources

- Use Google Search Console as the source of truth for PropLogAI's own clicks, impressions, CTR, average position, query ownership, and landing pages.
- Use Semrush for market estimates, keyword discovery, SERP features, and competitor research. Semrush estimates do not replace Search Console performance data.
- For this project, access Semrush directly in the signed-in browser through the NoxTools Semrush page. Start with Server 1 and switch to Servers 2–6 only when the current server has a login, limit, or unusable-data failure.
- Default to the India database and English-language terms. Record the keyword, database, server, checked date, and every reported metric. Preserve `n/a` or a blank field when Semrush does not report a value.
- Tell the user when all usable Semrush servers fail to authenticate or return usable data. Do not submit a support ticket or contact NoxTools without explicit instruction.

Do not invent volume, difficulty, ranking, clicks, impressions, or CTR. When Search Console is unavailable, label the keyword and priority as an `Editorial hypothesis`.

Glossary pages should own definition intent. Blog articles should own explanation, process, comparison, template, and problem-solving intent. Do not create a blog that merely repeats a glossary definition.
