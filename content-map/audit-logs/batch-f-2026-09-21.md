## URL-normalization finding

Live verification found a site-wide mismatch:

- The no-slash blog and glossary detail URLs return `200`.
- The equivalent trailing-slash URLs return `308` to the no-slash URL.
- The deployed canonical and `og:url` tags still declare the trailing-slash URL.

The local `BaseLayout.astro` files now remove trailing slashes from canonical and Open Graph URLs. Built detail and collection pages therefore match the URL Vercel actually serves. Regression checks fail if a generated canonical or `og:url` differs from the expected no-slash URL.

This correction is local. The deployed mismatch remains until an approved release.
