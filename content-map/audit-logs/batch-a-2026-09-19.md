## Audit findings addressed

The 2026-09-19 live audit identified these Batch A defects:

- 18 of 24 blog articles rendered a second H1 from a Markdown heading that repeated the layout title.
- `PropLog AI` appeared 48 times across 21 rendered pages.
- `Propol AI` appeared 14 times across 7 rendered pages.
- The glossary displayed 36 cards for 35 unique terms.
- `Daily Drawdown Limit` and `Maximum Daily Loss` used the same `daily-drawdown-limit` slug, causing a duplicate sitemap record.

## Changes made

### Blog repository

- Removed the repeated leading article title from all 18 affected Markdown files. The layout remains the single source of the page H1.
- Normalized legacy and typo spellings to the approved `PropLogAI` and `PropLogAI Coach` forms across blog content, the collection page, the article template, and the default social image.
- Added `scripts/validate-content.mjs` to reject article-body H1s, repeated leading title headings, and legacy brand spellings.
- Added `scripts/validate-build.mjs` to require 24 rendered article pages, exactly one H1 per article, and no legacy brand spelling in built pages.
- Added `npm run validate:content`, `npm run validate:build`, and `npm run check`.
- Ignored Astro-generated `src/env.d.ts` so local validation does not dirty the working tree.

### Glossary repository

- Removed the duplicate `Maximum Daily Loss` data object.
- Kept `Daily Drawdown Limit` as the canonical term and added `Maximum Daily Loss` as a searchable alias.
- Added alias data to glossary cards and included aliases in collection-page search.
- Added `Also known as Maximum Daily Loss` to the canonical detail page.
- Normalized `Propol AI Coach` and `Propol Coach` to `PropLogAI Coach`.
- Added `scripts/validate-content.mjs` to reject duplicate slugs/titles, missing required fields, invalid aliases, broken related-term references, and legacy brand spellings.
- Added `scripts/validate-build.mjs` to require 35 term pages, unique sitemap URLs, one `daily-drawdown-limit` sitemap entry, and exactly one H1 per term page.
- Added `npm run validate:content`, `npm run validate:build`, and `npm run check`.
- Ignored Astro-generated `.astro/` and `src/env.d.ts` files.
