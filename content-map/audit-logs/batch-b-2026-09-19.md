## Changes made

### Blog repository

- Preserved frontmatter `date` as the publication-date source of truth.
- Preserved optional `updatedDate` as the only source for a modification date; missing dates were not reconstructed.
- Added visible `Published` dates to all 24 article pages using semantic `<time datetime="YYYY-MM-DD">` markup.
- Added a visible `Updated` date only when `updatedDate` is later than the publication date.
- Added `article:published_time` to every article and `article:modified_time` only when stored update metadata exists.
- Added `BlogPosting` JSON-LD to every article.
- Added `BreadcrumbList` JSON-LD matching the existing navigation hierarchy.
- Added `CollectionPage` and 24-item `ItemList` JSON-LD to the blog index.
- Expanded source/build validation to reject missing or incomplete dates and schema.

### Glossary repository

- Did not invent historical publication dates.
- Added `glossaryPageUpdatedAt = 2026-09-19` as the shared page-revision source for this local migration.
- Added support for a future per-term `updatedAt` value, which overrides the shared fallback.
- Added visible `Page updated` dates to all 35 canonical term pages with semantic `<time>` markup.
- Added `article:modified_time` and `WebPage.dateModified` using the same stored source.
- Added `DefinedTerm` JSON-LD to every canonical term, including the `Maximum Daily Loss` alias on `Daily Drawdown Limit`.
- Added `BreadcrumbList` JSON-LD matching the visible glossary breadcrumb.
- Added `CollectionPage` and a 35-item `DefinedTermSet` to the glossary index.
- Replaced build-time sitemap dates with stored revision dates so rebuilding does not falsely change `lastmod`.
- Expanded source/build validation to reject missing or incomplete dates and schema.
