# Pre-Generation Checklist

Canonical checklist: `checklists/pre-generation-checklist.md`. This compatibility file retains PropLogAI’s source-register gates for older playbooks.

- [ ] One reader, question, and search intent are defined.
- [ ] The live inventory was checked for duplicate intent.
- [ ] Create, update, consolidate, or defer was decided.
- [ ] The brief is approved.
- [ ] Keyword evidence is named; unsupported priority is labelled editorial hypothesis.
- [ ] Every planned sensitive claim maps to a current source-register ID.
- [ ] Product and research rows are `Approved`; firm-rule rows are `Verified`.
- [ ] No required row is past its `review_by` date or marked `Needs Fact Check` or `Prohibited`.
- [ ] Firm-specific variation is identified.
- [ ] Product mention is necessary or intentionally omitted.
- [ ] Output type, path, item ID, status, and revision are defined.
