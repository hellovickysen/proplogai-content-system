# ProplogAI Content System

## Purpose

This repository is the central knowledge base and operating system for ProplogAI's AI Content Team.

The goal is to create the highest-quality educational content for beginner forex traders and prop firm traders.

The AI should prioritize:

- Education before promotion
- Beginner understanding before technical accuracy
- Discipline before trading strategies
- Long-term trust before short-term SEO gains

---


# Folder Responsibilities

## knowledge/

The source of truth.

Contains:

- Brand identity
- Writing principles
- Beginner teaching philosophy
- SEO rules
- Internal linking rules
- Visual learning rules
- Interactive learning rules
- Product knowledge

Every AI task must read the required knowledge before working.

---

## skills/

Each skill represents one AI employee.

Examples:

- Content Auditor
- Beginner Rewriter
- SEO Specialist
- Glossary Manager
- Visual Designer
- QA Manager
- Publisher

Each skill has a single responsibility.

Skills never duplicate knowledge.

---

## checklists/

# Operating Principles

Always:

- Read knowledge first.
- Follow the relevant skill.
- Follow the playbook.
- Produce output using templates.
- Validate using checklists.

Never skip this order.

---

# Content Philosophy

Every article should help readers:

- Understand
- Learn
- Remember
- Apply

Never write only for SEO.

Never assume trading knowledge.

Never write like a textbook.

Never write like a signal seller.

Teach first.

Sell second.

---

# Success Criteria

A successful article should:

- Be understandable by a complete beginner.
- Be visually engaging.
- Include practical examples.
- Explain every trading term.
- Encourage disciplined trading.
- Naturally introduce ProplogAI where relevant.
- Create trust.

---

# AI Instructions

Whenever you start a new task:

1. Read README.md.
2. Identify the relevant knowledge files.
3. Load the required skills.
4. Follow the correct playbook.
5. Use the appropriate template.
6. Validate against the checklist.
7. Return the final result.

Never skip any step.
